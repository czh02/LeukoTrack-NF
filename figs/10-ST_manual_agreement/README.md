# Figure 12: ST/manual velocity agreement

Manuscript figure: **Fig. 12** (`fig:st_velocity_agreement`). The historical
package index `10-` is retained in the directory name only.

Run from this directory:

```text
python code/make_velocity_manual_st_agreement.py
```

The script writes the publication PDF/PNG to `fig/`, and the paired-data and
summary CSV files to `data/`. It uses only package-relative paths; no legacy
`figs/2026721`, `figs/20260809` or `build` folders are required. The figure uses
the three-reader means; the individual manual-reader velocity sheets and the
original ST source videos remain in controlled storage.

---

*This public archive ships the rendered figure and the figure code only. The
`data/` inputs referenced above travel with the controlled reproducibility
package (Supplementary Section S2) and are not redistributed here.*
