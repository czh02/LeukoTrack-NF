# Figure 10: ST/manual velocity agreement

Run from this directory:

```text
python code/make_velocity_manual_st_agreement.py
```

The script writes the publication PDF/PNG and grayscale preview to `fig/`,
and the paired-data and summary CSV files to `data/`. It uses only package-
relative paths; no legacy `figs/2026721`, `figs/20260809`, or `build` folders
are required.
