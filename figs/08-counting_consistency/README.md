# Figure 11: Counting consistency

Manuscript figure: **Fig. 11** (`fig:dpa_refine_counting_consistency`). The
historical package index `08-` is retained in the directory name only.

Run from this directory:

```text
python code/make_counting_consistency_scatter.py
```

The script reads the paired plotting values from
`data/counting_consistency_points.csv` and writes the colour PNG and PDF renders
to `fig/`. The accompanying `_count_metrics_v2.csv`, `_count_raw.csv` and the
supplied counting workbook are retained as supporting audit materials in the
controlled reproducibility package.

---

*This public archive ships the rendered figure and the figure code only. The
`data/` inputs referenced above travel with the controlled reproducibility
package (Supplementary Section S2) and are not redistributed here.*
