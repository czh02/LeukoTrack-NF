# Figure 8: Counting consistency

Run from this directory:

```text
python code/make_counting_consistency_scatter.py
```

The script reads the paired plotting values from
`data/counting_consistency_points.csv` and writes the color, PDF, and grayscale
renders to `fig/`. The accompanying `_count_metrics_v2.csv`, `_count_raw.csv`,
and workbook are retained as supporting audit materials.
